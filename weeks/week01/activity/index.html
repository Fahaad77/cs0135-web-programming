Steps to Sort

The initial order is intentionally shuffled. Correct positions are marked only after you check your answer.

    Move the steps into the best order, then check your answer.

    Explanation

    The request-response process starts with the user and browser, then moves to the server, and ends when the browser turns the response into a page students can see and inspect.

    Reveal Complete Answer
    1. User enters a URL.
    2. Browser sends an HTTP request.
    3. Server finds or generates the resource.
    4. Browser receives an HTML response.
    5. Browser parses HTML and builds the DOM.
