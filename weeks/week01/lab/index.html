Week 1 Lab

Getting Started with HTML

Create, preview, inspect, and debug your first local website.

Estimated time45-60 minutes
PrerequisitesVS Code, browser, Live Server
SubmissionCompleted index.html
Download Starter Files Open Starter Return to Week Return to Course Home

Learning Outcomes

  • Create a valid beginner HTML document.
  • Preview a page with Live Server.
  • Identify a tag, element, and attribute in browser DevTools.
  • Fix a simple closing-tag error.

Folder Structure

starter/
`-- index.html

Stage 1: Open the Starter

  1. Download and unzip the starter files, or open the starter directly from this page.
  2. Open the starter folder in VS Code.
  3. Read the TODO comments before editing.

Stage 2: Build the Page

  1. Change the page title to My First CS 0135 Website.
  2. Fix the broken paragraph closing tag.
  3. Add a heading named Tools I will use.
  4. Add an unordered list with VS Code, Live Server, and Browser Developer Tools.

Stage 3: Preview and Inspect

  1. Start Live Server from VS Code.
  2. Open DevTools and inspect the main heading.
  3. Compare the source file with the live DOM.

Expected Browser Result

A page titled "My First CS 0135 Website" with a heading, two paragraphs, a three-item tools list, and one short question about the Web.

Modification challenge: Add a section named "One question I have about the Web" and write one question.

Completion Checklist

  • The file is named index.html.
  • The HTML document has DOCTYPE, html, head, and body.
  • The broken paragraph has been fixed.
  • Live Server opens the page without a file-not-found error.
  • You inspected one element in DevTools.

Troubleshooting

  • Live Server button is missing: check that the extension is installed and reload VS Code.
  • Browser shows the old page: save the file, then refresh the browser tab.
  • Page opens a folder listing: make sure the file is named exactly index.html.
  • Text appears outside the expected place: check for missing closing tags.

In-Class Review

The instructor will review a completed version in class.
