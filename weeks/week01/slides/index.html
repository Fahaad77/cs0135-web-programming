Internet vs World Wide Web

Internet

The global network infrastructure connecting devices and networks.

World Wide Web

A service on the Internet that uses URLs, HTTP/HTTPS, browsers, and web servers.

URL Anatomy

https://example.com/students/profile.html
  • https: secure protocol
  • example.com: domain name
  • /students/profile.html: path to a resource

HTTP and HTTPS

  • HTTP is the request-response language browsers and servers use.
  • HTTPS adds encryption and identity checks.
  • Status codes summarize what happened: 200, 404, 500.

Static and Dynamic Websites

Static

Files are sent mostly as written: HTML, CSS, images, and JavaScript.

Dynamic

Server code or browser code creates changing content based on data or user actions.

HTML, CSS, and JavaScript

  • HTML: meaning and structure
  • CSS: visual presentation
  • JavaScript: behavior and interaction

Student Club

HTML creates this heading. CSS makes it readable. JavaScript can respond when a user clicks.

How Browsers Render a Page

  1. Request the HTML document.
  2. Parse HTML into the DOM tree.
  3. Download linked CSS, images, and JavaScript.
  4. Calculate layout and paint pixels.

Complete First Website

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <h1>My First Website</h1>
  <p>I am learning how the web works.</p>
</body>
</html>

Code Walkthrough

  • <!DOCTYPE html> tells the browser to use modern HTML.
  • <head> contains page information for the browser.
  • <body> contains the content students see.
  • meta viewport helps the page fit mobile screens.

Predict the Output

<h1>CS 0135</h1>
<p>Web Programming and Design</p>
Reveal answer

The browser shows a large heading that says CS 0135, followed by a paragraph that says Web Programming and Design.

Tag, Element, Attribute

<p class="intro">Welcome to CS 0135.</p>
  • Tag: <p> and </p>
  • Element: the full paragraph from start tag to end tag
  • Attribute: class="intro" adds extra information

Find the Error

<h1>About Me<h1>
<p>My name is Sara.</p>

What is wrong, and what might the browser do?

Reveal answer

The first heading should close with </h1>. Browsers may repair the DOM, but valid source code is still the goal.

DevTools: Source vs DOM

  • View Source shows the original HTML sent to the browser.
  • Inspect shows the live DOM after the browser has parsed and repaired it.
  • The Console reports errors and lets us test small JavaScript commands later.

Accessibility Starts Today

  • Use meaningful headings in order.
  • Write link text that explains the destination.
  • Do not rely on color alone to communicate meaning.
  • Test with keyboard navigation.

Common Mistakes

  • Editing one file but previewing a different folder.
  • Forgetting to save before refreshing the browser.
  • Using opening tags where closing tags are needed.
  • Naming the home page Index.html or index.html.txt.
