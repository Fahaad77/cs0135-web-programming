URL Anatomy

Read a Web Address

URL
https://example.com/students/profile.html
Protocolhttps

Secure request rules.

Domainexample.com

Readable site name.

Path/students/profile.html

Resource location.

Protocol

HTTP and HTTPS

HTTP

The request-response language browsers and servers use.

HTTPS

Adds encryption and identity checks while data travels.

Status

200, 404, and 500 summarize what happened.

Site Types

Static and Dynamic Websites

Static

Files are sent mostly as written: HTML, CSS, images, and JavaScript.

Dynamic

Server code or browser code creates changing content based on data or user actions.

</body>
</html>

Walkthrough

What Each Part Does

<!DOCTYPE html>

Tells the browser to use modern HTML.

<head>

Contains page information for the browser.

<body>

Contains the content students see.

meta viewport

Helps the page fit mobile screens.

Debug prompt

What is wrong, and what might the browser do?

Reveal answer

The first heading should close with </h1>. Browsers may repair the DOM, but valid source code is still the goal.

DevTools

Source vs DOM

View Source

Shows the original HTML sent to the browser.

Inspect

Shows the live DOM after the browser has parsed and repaired it.

Console

Reports errors and lets us test small JavaScript commands later.
