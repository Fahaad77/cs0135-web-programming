Week 3 Activity

Read, Predict, and Debug CSS

Practice CSS rule anatomy, selectors, cascade reasoning, contrast, and DevTools habits.

Return to Week Return to Course Home

Part 1: Label the CSS Rule

Identify the selector, property, and value in this rule.

h1 {
  color: #006b5f;
  font-size: 2.5rem;
}
Self-check

h1 is the selector. color and font-size are properties. #006b5f and 2.5rem are values.

Part 2: Match Selectors to Elements

  1. .card
  2. #course-title
  3. nav a
  4. main > section

Match each selector to a likely HTML target.

Self-check

Class card, unique element with that ID, links inside nav, and section elements that are direct children of main.

Part 3: Predict the Winner

p { color: black; }
.note { color: teal; }
p { color: maroon; }

What color is <p class="note">?

Self-check

teal, because the class selector is more specific than the element selectors.

Part 4: Correct the Stylesheet Link

<link rel="stylesheet" href="style.css">

The real file is named styles.css.

Self-check
<link rel="stylesheet" href="styles.css">

Part 5: Improve Contrast

A paragraph uses pale green text on a pale background. Choose a darker text color and explain why.

Self-check

A dark color such as #10231f on a light background improves readability and accessibility.

Part 6: DevTools Inspection

  1. Open any Week 3 starter page.
  2. Inspect the main heading.
  3. Temporarily change its color.
  4. Copy the useful change into styles.css.
Self-check

The Styles panel should show which selector set the heading color and whether any rules were crossed out.
