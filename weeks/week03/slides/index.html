CSS locations

Inline, Internal, External

Inline

Inside a single style attribute. Quick, but hard to maintain.

Internal

Inside <style> in one HTML file. Useful for tiny demos.

External

Separate .css file linked from HTML. Course default.

Modern correction

Priority Is Not Just Location

  1. Importance
  2. Specificity
  3. Source order
  4. Inheritance/defaults

Inline rules often win because they have high specificity, but the cascade is more than inline > internal > external.

Selectors

Reusable Classes

HTML + CSSclass
<section class="card highlight">...</section>

.card {
  background-color: white;
  padding: 1rem;
}

.highlight {
  border-left: 6px solid #007c6c;
}

Class rule

Use classes for patterns that repeat, such as cards, warnings, buttons, and badges.

Selectors

One ID, Used Carefully

CSSID selector
#course-title {
  letter-spacing: 0.04em;
}

Course guidance

An ID must be unique. Prefer classes for visual styling unless one unique target is truly needed.

Grouping

One Rule, Many Selectors

CSSgrouped selectors
h1,
h2,
h3 {
  line-height: 1.1;
  color: #10231f;
}

Grouping reduces repetition and keeps headings consistent.

Relationships

Descendant Versus Child

.profile a

Any link inside .profile, even if deeply nested.

.profile > a

Only direct child links one level below .profile.

.profile a { color: #005f53; }
.profile > a { font-weight: bold; }

Universal selector

Useful, But Broad

CSScommon reset
* {
  box-sizing: border-box;
}

Meaning

The universal selector targets every element. Use it for intentional global defaults, not random styling.

Interaction

:hover and :focus

CSSmouse and keyboard
a:hover {
  color: #00483f;
}

a:focus {
  outline: 3px solid #b78b20;
  outline-offset: 3px;
}

Accessibility habit

Hover helps mouse users. Focus helps keyboard users know where they are.

Text properties often inherit. Layout properties like margin, padding, and border usually do not.

Specificity

Which Rule Wins?

CSSpredict
p { color: black; }
.note { color: teal; }
#summary { color: maroon; }

Prediction

For <p id="summary" class="note">, the ID selector wins unless a later rule has higher cascade power.

Source order

When Specificity Ties

CSSlater wins
.card { background-color: white; }
.card { background-color: #eef4f1; }

Both selectors have the same specificity, so the later rule wins.

Contrast

Color Must Be Readable

Hard to read

Light green text on a pale background reduces readability.

Better

Dark text on a light background is easier for more students.

Check contrast before choosing a palette for the project style guide.

DevTools

Inspect Before Guessing

  1. Right-click an element
  2. Inspect
  3. Read Styles panel
  4. Toggle or edit temporarily

DevTools changes are temporary. Copy good fixes back into styles.css.

Common mistake

Broken Stylesheet Link

<link rel="stylesheet" href="style.css">

Fix

If the file is named styles.css, the link must say href="styles.css".
