Week 3 Lab

Style Your Profile Page

Transform the Week 2 profile into a maintainable page styled with an external stylesheet.

Estimated time60-75 minutes
PrerequisitesWeek 2 semantic profile page
SubmissionProfile folder with HTML and CSS
Download Starter Files Open Starter Return to Week Return to Course Home

Learning Outcomes

  • Connect an external styles.css file.
  • Use element, class, and one optional ID selector.
  • Apply readable typography, colors, spacing, link states, and focus states.
  • Validate HTML and CSS after styling.

Folder Structure

starter/
|-- index.html
`-- styles.css

Required Work

  1. Keep styles in styles.css, not inline.
  2. Use at least one element selector and two reusable classes.
  3. Use one ID only if a unique page title needs special styling.
  4. Set a font stack, readable font size, and line height.
  5. Create background and foreground colors with accessible contrast.
  6. Add link hover and visible keyboard focus states.
  7. Use consistent spacing around sections and cards.

Expected Result

A student profile page with a clear heading, readable sections, styled navigation links, reusable cards, and visible focus outlines.

Extension: Add a .button-link class and use it for one project link.

Checklist

  • HTML links to styles.css.
  • CSS includes element and class selectors.
  • Text has readable contrast and spacing.
  • Links include hover and focus styles.
  • Page validates and loads without missing files.

In-Class Review

We will review a completed version in class and compare it with the starter file.
