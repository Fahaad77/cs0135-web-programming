Week 5 Lab

Create a Catalog in XML and JSON

Represent the same 5-8 record dataset in both XML and JSON, then document the tradeoffs.

Estimated time75-90 minutes
PrerequisitesHTML nesting and Week 5 data-format lecture
Submissioncatalog.xml, catalog.json, README.md

Learning Outcomes

  • Create well-formed XML with elements, one attribute, nesting, and an entity or CDATA where appropriate.
  • Create equivalent valid JSON using an array of objects.
  • Document at least three differences between XML and JSON.
  • Choose a format for a modern web API.

Folder Structure

Required Work

  1. Create 5-8 records for a course, product, service, team, or portfolio catalog.
  2. Use meaningful XML elements and at least one XML attribute.
  3. Maintain proper nesting and quoted attributes.
  4. Include one entity or CDATA example where appropriate.
  5. Create an equivalent JSON representation with an array of objects.
  6. Validate both files and describe fixes in the README.

Expected Result

A small dataset that can later be loaded by JavaScript/AJAX, with matching information in XML and JSON.

Extension: Add a nested object or nested XML element for contact or location data.

Checklist

  • XML has one root element.
  • XML tags are properly nested and case-consistent.
  • JSON has double-quoted keys and no trailing commas.
  • Both files contain the same records.
  • README compares at least three differences and chooses an API format.

In-Class Review

We will validate representative files and discuss when XML remains useful.
