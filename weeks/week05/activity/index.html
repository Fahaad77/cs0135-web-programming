Week 5 Activity

XML and JSON Data Clinic

Find syntax errors, choose data modeling options, and convert a record between XML and JSON.

Return to Week Return to Course Home

Part 1: Find Five XML Errors

<catalog>
  <item id=p1>
    <name>USB Cable</title>
    <price>25</price>
  <item>
</products>
Self-check

Unquoted attribute, mismatched name/title, missing close for first item, second item closes incorrectly, and root closes as products.

Part 2: Element or Attribute?

Choose where to store product ID, product name, long description, and category.

Self-check

ID and category can be attributes; name and long description are better as elements.

Part 3: Namespace Collision

Two vocabularies both use title. Propose prefixes.

Self-check

For example, web:title and book:title with two namespace declarations.

Part 4: Identify Invalid JSON

{
  name: "USB Cable",
  "price": 25,
}
Self-check

The key name needs double quotes, and the trailing comma after 25 must be removed.

Part 5: Convert XML to JSON

<course id="CS0135">
  <title>Web Programming</title>
  <hours>3</hours>
</course>
Self-check
{
  "id": "CS0135",
  "title": "Web Programming",
  "hours": 3
}
