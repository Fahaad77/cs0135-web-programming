Part 1

Every Element Is a Box

Layout becomes easier when you can see the invisible boxes around content.

Box model

Four Layers

Content

Text or image.

Padding

Space inside the border.

Border

Line around padding.

Margin

Space outside the element.

Box sizing

Make Width Predictable

CSSglobal default
* {
  box-sizing: border-box;
}

With border-box, the declared width includes content, padding, and border.

Margin or padding?

Inside Space Versus Outside Space

.card {
  padding: 1rem;
  margin-bottom: 1rem;
  border: 2px solid #d7dfdc;
}

Memory rule

Padding separates content from its border. Margin separates one element from another.

Borders

Shorthand and Radius

CSSborder
.notice {
  border: 2px solid #007c6c;
  border-radius: 8px;
}

Margin collapse

A Basic Warning

Vertical margins between block elements can sometimes combine instead of adding together. If spacing looks surprising, inspect the box model in DevTools.

Lists and text

Style Lists Without Breaking Meaning

CSSlist and text review
nav ul {
  list-style-type: none;
  padding: 0;
}

p {
  text-align: left;
}

Backgrounds

Color First, Images Carefully

background-color

background-image

Part 2

Choose the Right Container

Use meaningful HTML when it exists, and generic containers only when needed.

Display behavior

Block Versus Inline

Block

Starts on a new line and can take full available width. Examples: div, section, p.

Inline

Flows inside text. Examples: span, a, strong.

Semantic first

div and span Have No Meaning

Use header

Introductory page or section content.

Use nav

Major navigation links.

Use main

The primary page content.

Use div

Only when you need a generic layout wrapper.

Part 3

Flexbox Aligns Groups of Boxes

Flexbox is our primary Week 4 layout method. Float is for text wrapping or legacy reading.

Flex model

Container and Items

flex container
contains
item
item
item

Main axis follows flex-direction; cross axis runs perpendicular.

Card layout

Flexible Cards

CSScard grid
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

.card {
  flex: 1 1 250px;
}

Alignment

Main and Cross Axis

CSSnavigation
.site-nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Wrapping

When There Is Not Enough Room

No wrap

Items may overflow the viewport.

flex-wrap: wrap

Items can move onto another line.

Responsive units

Use Flexible Measurements

%

Relative to parent.

rem

Relative to root font size.

vw

Relative to viewport width; use carefully.

max-width

Stops content from becoming too wide.

Media query

Mobile Adjustment

CSSbreakpoint
@media (max-width: 700px) {
  .site-nav {
    flex-direction: column;
    align-items: stretch;
  }
}

Desktop and mobile

Same Content, Different Arrangement

Desktop: nav links in a row, cards beside each other.

Mobile: nav stacks, cards wrap, image stays fluid.

DevTools

Device Toolbar

  1. Open DevTools
  2. Toggle device toolbar
  3. Try 390px width
  4. Check scrolling and focus

Float context

Where Float Still Belongs

Reasonable

Text wrapping around a small image.

Avoid

Building the whole page layout with floats.

Common mistake

Fixed Width Page

.page { width: 1100px; } can force horizontal scrolling on phones.

Use width: min(90%, 1100px) or similar responsive constraints.
