Week 4 Lab

Responsive Project Homepage

Build a responsive homepage for the semester project using semantic HTML, Flexbox, and one media query.

Estimated time75-90 minutes
PrerequisitesWeek 3 external CSS
SubmissionHomepage folder plus screenshots
Download Starter Files Open Starter Return to Week Return to Course Home

Learning Outcomes

  • Use semantic page structure.
  • Create responsive navigation.
  • Build a Flexbox card/content layout.
  • Use the box model, responsive image rules, and one media query.

Folder Structure

starter/
|-- index.html
|-- styles.css
`-- images/
    `-- course-pattern.svg

Required Work

  1. Use header, nav, main, section, and footer.
  2. Build navigation to planned pages or page sections.
  3. Use display: flex, gap, and flex-wrap.
  4. Include a responsive image with max-width: 100%.
  5. Add one media query for narrow screens.
  6. Test desktop and mobile widths with DevTools.

Expected Result

A project homepage with a clear header, responsive nav, hero area, flexible cards, local image, visible focus states, and no horizontal scrolling on mobile.

Extension: Add a second card row for project features.

Checklist

  • Semantic page regions are present.
  • Cards wrap instead of overflowing.
  • Image stays responsive.
  • One media query changes the navigation or layout.
  • Desktop and mobile screenshots are ready.

In-Class Review

We will compare the starter and completed layouts and inspect the box model in DevTools.
