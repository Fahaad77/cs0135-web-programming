Week 4 Activity

Box Model and Flexbox Clinic

Practice layout reasoning before building a responsive project homepage.

Return to Week Return to Course Home

Part 1: Label the Box Model

Label content, padding, border, and margin on a sketch of a card.

Self-check

Content is the text/image area; padding is inside the border; border surrounds padding; margin is outside the border.

Part 2: Calculate Width

.box { width: 300px; padding: 20px; border: 5px solid #000; }

With default content-box, what is the total rendered width?

Self-check

350px: 300 + 20 + 20 + 5 + 5.

Part 3: Border-box Difference

How does box-sizing: border-box change the previous answer?

Self-check

The total width stays 300px; content space shrinks to make room for padding and border.

Part 4: Predict Flexbox

.cards { display: flex; flex-wrap: wrap; gap: 1rem; }
.card { flex: 1 1 250px; }
Self-check

Cards sit in a row when space allows and wrap to new lines when space is tight.

Part 5: Fix Missing Wrap

A card row overflows on phones. Which Flexbox property is probably missing?

Self-check

flex-wrap: wrap;

Part 6: Margin or Padding?

  1. Space inside a card around text.
  2. Space between two cards.
Self-check

Use padding inside the card and margin/gap between cards.

Part 7: Breakpoint

What does @media (max-width: 700px) mean?

Self-check

Apply the enclosed rules when the viewport is 700px wide or narrower.

Part 8: Replace Float

A whole page layout uses floated columns. Rewrite the layout idea using a flex container and flexible cards.

Self-check

Use display:flex, gap, flex-wrap:wrap, and flexible item sizes.
