Week 2 Lab

Personal Profile Page

Build a multi-section semantic HTML page that can grow into your semester project.

Estimated time60-75 minutes
PrerequisitesWeek 1 HTML file workflow
SubmissionProfile page folder
Download Starter Files Open Starter Return to Week Return to Course Home

Learning Outcomes

  • Use semantic regions including header, nav, main, section, article, and footer.
  • Add meaningful formatting with at least four different text-formatting elements.
  • Display a local image using a relative path from an images folder.
  • Write meaningful alternative text and sensible image dimensions without distortion.
  • Add one small inline-style example clearly identified as a CSS preview.
  • Validate HTML and fix common nesting or path errors.

Folder Structure

starter/
|-- index.html
`-- images/
    `-- profile-workspace.svg

The image path from index.html is images/profile-workspace.svg.

Stage 1: Page Regions

  1. Update the document title and main heading with your own name.
  2. Add navigation links for About, Goals, Projects, and Contact.
  3. Confirm every navigation link points to a matching section ID.

Stage 2: Meaningful Text Formatting

  1. Replace placeholder text with your own profile introduction.
  2. Use at least four different formatting elements such as strong, em, mark, small, del, ins, sub, or sup.
  3. Use strong for importance and em for stress emphasis. Do not use b or i when a semantic element is better.

Stage 3: Local Image

  1. Keep the provided images folder in the same folder as index.html.
  2. Add the profile image with src="images/profile-workspace.svg".
  3. Write useful alt text that describes the image purpose in your profile page.
  4. Add sensible width and height values without squashing the image.
<img
  src="images/profile-workspace.svg"
  alt="Desk with a laptop, notebook, and web design sketches"
  width="500"
  height="350"
>

Stage 4: CSS Preview

  1. Add one small inline-style example to a heading or section.
  2. Use a readable color combination.
  3. Add a short note in the page text that says this is a CSS preview for Week 3.
<h2 style="background-color: powderblue;">
  Learning Goals
</h2>

Stage 5: Project and Contact Sections

  1. Add one project idea inside an article.
  2. Create a small study-plan table with a caption and header cells.
  3. Add a basic contact form with labels for every input.

Expected Browser Result

A personal profile page with semantic sections, working navigation, meaningful formatting, a visible local image, useful alt text, a small CSS preview, table data, and a labeled form.

Modification challenge: Add a second project idea and mark the newer idea with ins.

Completion Checklist

  • The page has one h1 and logical section headings.
  • Navigation links jump to the correct sections.
  • At least four formatting elements are used meaningfully.
  • The local image loads from images/profile-workspace.svg.
  • The image has useful alt text and sensible dimensions.
  • One inline-style example is labeled as a CSS preview.
  • The table is used for tabular data, not layout.
  • Every form control has a visible label.
  • The finished page passes HTML validation.

Troubleshooting

  • Image does not show: check the path images/profile-workspace.svg and folder spelling.
  • Image looks stretched: use dimensions that match the image shape, or remove one dimension and let the browser preserve proportion.
  • Navigation link does not move: check that href="#projects" matches id="projects".
  • Formatting looks right but meaning is wrong: use strong for importance and em for emphasis.
  • Validator reports mismatched tags: check opening and closing tags from the inside out.
