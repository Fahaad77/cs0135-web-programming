<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Personal Profile</title>
</head>
<body>
</body>
</html>

Walkthrough

What Each Part Does

lang="en"

Identifies the page language for browsers, search tools, and assistive technology.

charset="UTF-8"

Supports common characters and avoids strange text display problems.

viewport

Helps the page adapt to phones, tablets, and laptops.

title

Labels the browser tab and gives the page a document name.

Part 1

Text Formatting Is Also Meaning

Many elements change appearance, but their real job is to describe the purpose of the text.

Formatting map

Text Elements in Groups

Highlight and annotation

Science and math

Semantic choice

<b> Versus <strong>

<b>

Draws attention visually when the text is not more important.

<b>HTML</b> term

<strong>

Marks text with strong importance, warning, or urgency.

<strong>Important:</strong>

They may both look bold, but they do not mean the same thing.

Semantic choice

<i> Versus <em>

<i>

Marks text set off from normal prose, such as a technical term or title.

<i>viewport</i>

<em>

Marks stress emphasis that can change how a sentence is understood.

This word is <em>emphasized</em>.

They may both look italic, but em carries spoken emphasis.

Part 2

A Small CSS Preview

Today we only preview inline style. Week 3 teaches CSS properly.

Inline style

Color Belongs to CSS

HTMLCSS preview
<h1 style="background-color: powderblue;">
  This is a heading
</h1>

This is a heading

style is an attribute. background-color is a CSS property. powderblue is the value.

This affects only this element. It is useful for a preview, but it is not the long-term way to style a site.

Part 3

Images Need Working Paths

The browser can only display an image when src points to the right location.

Absolute URL

Full Web Address

HTMLabsolute URL
<img
  src="https://example.com/images/student.jpg"
  alt="Student working on a laptop"
>

What to remember

  • Starts with a complete web address.
  • Depends on another website staying available.
  • May involve copyright or permission issues.
  • Good for learning the idea, not for hotlinking random images.

Relative URL

Project File Path

HTMLrelative path
<img
  src="images/student.jpg"
  alt="Student working on a laptop"
>
week02-project/
|-- index.html
`-- images/
    `-- student.jpg

images/student.jpg starts beside index.html, opens images, then loads student.jpg.

Path detail

images/ Versus /images/

src="images/student.jpg"

Start from the folder containing the current HTML file.

src="/images/student.jpg"

Start from the website root. This can break when the site is inside a course folder.

For this lab, use the local relative path: images/profile-workspace.svg.

Accessible images

Image Markup Students Should Write

HTMLimage with dimensions
<img
  src="images/student.jpg"
  alt="Student working on a laptop"
  width="500"
  height="600"
>

src

Where the image file is.

alt

What the image communicates.

width

Display width and reserved space.

height

Display height and reserved space.

Image quality

Avoid Distortion and Vague Alt Text

Weak

<img src="student.jpg" alt="image"
     width="500" height="100">

Path may be wrong, alt text is vague, and dimensions can squash the image.

Better

<img src="images/student.jpg"
     alt="Student working on a laptop"
     width="500" height="600">

Path is specific, alt text has purpose, and dimensions match the image shape.

Debugging

Common Image Mistakes

Folder name

image and images are different paths.

File name

Check spelling, spaces, and extension.

Wrong start

Do not include the whole project folder beside index.html.

Missing alt

Every meaningful image needs useful alt text.

Links and lists

Use Elements for Their Jobs

HTMLnavigation and list
<nav>
  <a href="#about">About</a>
  <a href="#goals">Goals</a>
  <a href="#contact">Contact</a>
</nav>

<ul>
  <li>Write valid HTML</li>
  <li>Use meaningful images</li>
</ul>

Good link text tells the destination.

A list groups related items. An ordered list is for steps or rank.

Tables

Use Tables for Tabular Data

HTMLstudy plan table
<table>
  <caption>Weekly Study Plan</caption>
  <tr><th>Day</th><th>Task</th></tr>
  <tr><td>Monday</td><td>Read HTML notes</td></tr>
</table>

Do not use tables only to arrange page layout.

Forms

Labels Make Inputs Usable

HTMLintroductory form
<form>
  <label for="message">Message</label>
  <textarea id="message" name="message"></textarea>

  <label for="email">Email</label>
  <input id="email" name="email" type="email">

  <button type="submit">Send</button>
</form>

Check the pair

label for="email" must match input id="email".
