Week 2 - CS 0135

HTML Foundations

Build a semantic personal profile page that becomes the base for the semester project.

Learning Outcomes

  • Write a valid HTML document structure.
  • Use headings, paragraphs, emphasis, lists, links, images, tables, and forms correctly.
  • Choose semantic elements for page regions.
  • Validate HTML and fix common nesting errors.

Prior-Knowledge Check

  1. Which visible heading should usually describe the whole page?
  2. What file name does a web server commonly open first?
  3. What is one reason a browser may show a broken image icon?
Reveal sample answers

h1, index.html, and a missing or incorrect image path.

HTML Document Structure

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Personal Profile</title>
</head>
<body>
</body>
</html>

Code Walkthrough

  • lang="en" identifies the page language.
  • charset="UTF-8" supports common characters.
  • viewport helps responsive layout on phones.
  • title labels the browser tab.

Headings and Paragraphs

<h1>Aisha Ahmed</h1>
<p>First-semester cybersecurity student learning web design.</p>
<h2>Learning Goals</h2>
<p>I want to build clear, secure, and accessible websites.</p>

Strong and Emphasis

<p>Submit the project <strong>before Week 13</strong>.</p>
<p>Use <em>clear</em> link text.</p>
  • strong marks importance.
  • em marks stress emphasis.
  • They are not just bold and italic.

Lists

<h2>Skills</h2>
<ul>
  <li>HTML structure</li>
  <li>Browser DevTools</li>
</ul>
<ol>
  <li>Plan content</li>

Use lists for related items

Choose ordered lists only when sequence matters.

Links and Useful Link Text

<a href="https://developer.mozilla.org/">Read MDN Web Docs</a>
<a href="projects.html">View my projects</a>

Avoid link text like "click here." The text should explain the destination.

Images and Alternative Text

<img src="images/profile-workspace.svg"
     alt="Desk with a laptop, notebook, and web design sketches">
  • src points to the file.
  • alt communicates the image purpose.
  • Decorative images may use empty alt text: alt="".

File Paths

profile-site/
|-- index.html
|-- projects.html
`-- images/
    `-- profile-workspace.svg

images/profile-workspace.svg means: start beside index.html, open the images folder, then load the image.

Semantic Page Structure

<header>...</header>
<nav>...</nav>
<main>
  <section>...</section>
  <article>...</article>
</main>
<footer>...</footer>

Tables Are for Tabular Data

<table>
  <caption>Weekly Study Plan</caption>
  <tr><th>Day</th><th>Task</th></tr>
  <tr><td>Monday</td><td>Read HTML notes</td></tr>
</table>

Do not use tables only to arrange page layout.

Introductory Forms

<form>
  <label for="message">Message</label>
  <textarea id="message" name="message"></textarea>

  <label for="email">Email</label>
  <input id="email" name="email" type="email">

  <button type="submit">Send</button>
</form>

HTML Comments

<!-- Main profile content starts here -->

Use comments to clarify structure during learning. Do not use comments to hide private information.

HTML vs XHTML Context

  • XHTML used XML-style strict syntax.
  • Modern courses should teach HTML as the main standard.
  • Writing lowercase tags, quoted attributes, and well-nested elements is still a good habit.

Knowledge Check

  1. What is the purpose of <main>?
  2. When should you use a table?
  3. Why should an input have a label?
  4. What does the HTML validator help you find?

Common Mistakes

  • Using headings only to make text look large.
  • Writing vague alt text such as "image" or "picture."
  • Using tables for page layout instead of data.
  • Forgetting that id values and fragment links must match.

Recap and Exit Ticket

  • HTML describes structure and meaning.
  • Semantic elements make pages clearer for humans and tools.
  • Validation catches mistakes early.

Exit ticket: paste one fixed validation error and explain the fix.
