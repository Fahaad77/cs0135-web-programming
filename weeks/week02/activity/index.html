Feedback and Retry

  1. Run the snippet through the HTML validator.
  2. Fix one error at a time, then validate again.
  3. Write three sentences explaining the problems you fixed.

Submit

  • The corrected code.
  • Three sentences explaining the problems you fixed.
  • A screenshot or copied message from the HTML validator.

Marks: 4 marks for structure, nesting, explanation, and validation evidence.
