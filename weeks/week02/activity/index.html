Week 2 Activity

Choose, Trace, and Fix HTML

Practice semantic text formatting, image paths, and useful alternative text before the lab.

Return to Week Return to Course Home

Part 1: Choose the Better Element

For each situation, choose a semantic HTML element and explain your choice in one short phrase.

  1. A warning sentence that students must read before submitting.
  2. A word that should be spoken with stress in a sentence.
  3. A changed price where the old value should remain visible.
  4. The chemical formula for water.
  5. A highlighted score in a feedback paragraph.
Self-check

Possible answers: strong, em, del plus ins, sub, and mark.

Part 2: Correct the Misuse

Rewrite the snippet so the meaning is clearer. Keep the visible result beginner-friendly.

<p><b>Important:</b> Submit the profile page by Thursday.</p>
<p>I am <i>very excited</i> to build my first website.</p>
Self-check 
<p><strong>Important:</strong> Submit the profile page by Thursday.</p>
<p>I am <em>very excited</em> to build my first website.</p>

Part 3: Absolute or Relative?

Label each image path as absolute or relative.

  1. https://example.com/images/student.jpg
  2. images/student.jpg
  3. /images/student.jpg
  4. ../assets/profile-workspace.svg
Self-check

1 is absolute. 2 and 4 are relative. 3 is root-relative, which starts from the site root instead of the current file.

Part 4: Which Path Works?

The HTML file is week02-project/index.html. Choose the path that reaches the image.

week02-project/
|-- index.html
`-- images/
    `-- student.jpg
  1. student.jpg
  2. images/student.jpg
  3. week02-project/images/student.jpg
Self-check

images/student.jpg works because the browser starts beside index.html, opens the images folder, then loads student.jpg.

Part 5: Write Useful Alt Text

Write alt text for a photo that shows a student working on a laptop beside a notebook and phone.

  • Avoid vague text such as image or picture.
  • Describe the content or purpose in the page context.
  • Use alt="" only if the image is decorative.
Self-check

A useful answer could be: Student working on a laptop beside a notebook and phone.

Submit
