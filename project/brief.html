Course Project Brief

Build a beginner-level website for a small business, service, student group, portfolio, or community topic.

Core Requirements

  • Work in groups of 3-4 students unless the instructor approves another arrangement.
  • Create 3-4 linked pages: Home, About, Services or Products, and Contact.
  • Use semantic HTML and external CSS. Optional JavaScript may be added after the required pages work.
  • Use original writing and properly licensed or self-created images.
  • All members must understand and be able to explain the submitted code.

Submission

Submit one ZIP file and one short PDF preview/report in Week 13. The ZIP filename should be Section_GroupName_CS0135_Project.zip.
