Project Milestones

  1. Week 1: Choose topic, group, and folder structure.
  2. Week 2: Build personal/profile prototype page.
  3. Week 3: Draft style guide: colors, type, spacing.
  4. Week 4: Create responsive home page and navigation.
  5. Week 5: Create a project data.json file with at least five objects for later JavaScript/AJAX use.
  6. Week 6: Add media responsibly with alt text and captions where needed.
  7. Week 8: Add one small JavaScript interaction.
  8. Week 10: Review form structure and validation expectations.
  9. Week 12: Usability and accessibility review.
  10. Week 13: Final submission and short presentation.
